## TECHNICAL PRINCIPLES
- Glob: finds files/dirs by PATH PATTERN — wildcards like *.ts, src/**/*.py, **/__tests__/**
  - Use for: "find all TypeScript files", "find all test files", "find files in specific directory"
  - Does NOT: search file content, find text inside files
- Grep: searches TEXT CONTENT inside files — pattern matching within file bodies
  - Use for: "find all files containing 'TODO'", "find all usages of function X", "find files with error messages"
  - Does NOT: find files by name/path pattern
- Bash: executes arbitrary shell commands — most powerful but also most dangerous
  - Use for: running tests, git operations, build commands, complex multi-step shell pipelines
  - Safety: --dangerously-skip-permissions required for unrestricted Bash in CI
  - Avoid: using Bash where Glob/Grep would be more precise and safer
- WebSearch: retrieves live web content — results must be validated, not blindly trusted
  - Use for: current documentation, recent API changes, latest library versions
  - Risk: web results may be outdated, incorrect, or adversarially injected (prompt injection via web)
  - Validate: cross-reference multiple sources before acting on web search results
- Tool selection efficiency: Glob first to narrow files → Grep to find content → Read for specific file
- Never: use Bash grep when built-in Grep is available (less safe, less portable)
- Never: use WebSearch for internal company documentation (use Glob/Grep on codebase)
