## TECHNICAL PRINCIPLES
- Chain-of-Thought (CoT): model reasons step-by-step before answer — reduces hallucination for complex tasks
- Extended thinking: budget_tokens parameter controls reasoning depth (API parameter, not a prompt tag)
- When CoT helps: multi-step reasoning, ambiguous classification, evidence weighing, math, legal analysis
- When CoT does NOT help (adds latency with no benefit): simple fact lookup, formatting, single-step retrieval
- budget_tokens too low: model truncates reasoning mid-analysis — same errors as no CoT
- budget_tokens too high: unnecessary cost for simple tasks — budget should match task complexity
- Streaming + extended thinking: thinking blocks stream progressively — consumer must handle thinking block type
- Thinking block vs final answer: thinking is NOT shown to user; only content after thinking is shown
- CoT + few-shot: including thinking process in few-shot examples teaches model the reasoning pattern
- CoT for structured output: reason about each field before outputting JSON — fewer missing/hallucinated fields
- prefilling assistant turn: can be combined with CoT but must not interrupt thinking block
- Verification loop: model can "double-check" in thinking before committing to answer
