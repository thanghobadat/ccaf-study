## TECHNICAL PRINCIPLES
- `claude -p "prompt"`: single-turn non-interactive (headless) execution
- stdin piping: `cat file.txt | claude -p "Summarize this"` — feed file content to Claude
- `--output-format json`: structured output for programmatic parsing
- `--output-format stream-json`: streaming version for progressive output
- `--max-turns N`: limit agentic turns in headless session
- Exit codes: 0 = success, non-zero = error — use for conditional shell logic (`&&`, `||`)
- Headless + tools: claude -p can still call tools (Bash, Grep, Glob) — it's still agentic
- Environment variables: ANTHROPIC_API_KEY must be set; MODEL can be set via --model flag
- Composing pipelines: `claude -p "..." | jq '.result' | another-command`
- Headless vs interactive: no TTY in headless — prompts cause hangs without --dangerously-skip-permissions
- `--no-tools`: disable all tool use for simple Q&A without agentic behavior
- Output capture: `OUTPUT=$(claude -p "..." --output-format json)` then `echo $OUTPUT | jq ...`
- Parallel headless: run multiple claude -p in parallel with & and wait
